Results & Certificate Import

Import finalized participant data, validate it, auto-generate Certificate IDs, then export a ready-to-publish dataset. This is a client-side build tool — no data is uploaded to any server.

Everything here runs in your browser. To publish, download the generated certificates.js and commit it to the site’s data/ folder. Results and certificates then become available automatically.
